# 📦 Campus Logistics & Route Mapper

## 📌 Project Overview
As an Information Science major and an employee at **Big Red Shipping & Hired Hands (Cornell Student Agencies)**, I manage complex logistics and scheduling for 20+ daily work orders. 

I built this Python project to programmatically visualize university-wide shipping routes. By inputting daily work order data, this script generates an interactive geographic map to help optimize operational efficiency and resolve logistical bottlenecks.

## 🛠️ Tech Stack
- **Python** 
- **Pandas:** Data structuring and management
- **Folium / Leaflet.js:** Geospatial visualization and interactive mapping
